How Kelvi AI Works

An architectural deep-dive into sovereign Indian speech recognition, dual-engine hybrid reasoning, conversational state machines, and zero-drop telephony guardrails.

1. Smart Hybrid Gating Engine (Zero Latency Traps)

Traditional voice agents route every spoken turn to a large LLM, introducing 2.5–4.0 second delays that cause callers to hang up or speak over the agent. Kelvi AI implements a smart dual-path gating engine:

Fast Path (<2ms)

Simple confirmations ("ശരി", "അതെ", "വേണ്ട") and unambiguous date/time requests resolve locally via IST temporal rules with 0 remote LLM calls and 0 Gnani credits consumed.

Reasoning Path (Evon v3.3)

Complex colloquial idioms, back-references, or colloquial exasperation trigger the hosted Evon 30B MoE endpoint, strictly bounded to max_tokens: 150.

Automatic Fail-Safe

If the remote LLM takes >2.0s or encounters network jitter, the session safely defaults to local guardrails. The phone call never freezes.

2. Conversational Memory Trap Shield

Real Indian phone conversations feature interruptions, conversational annoyance, and non-linear back-references. Kelvi AI’s state machine protects against three common agent failures:

Filler Immunity

Expressions like "ഓൾറെഡി പറഞ്ഞല്ലോ" ("I already told you") or "മിസ്റ്റർ" are stripped from the patient name slot to prevent saving junk entities.

Slot Retention on Rejection

Phrases like "വേണ്ട, അപ്പോഴത്തേക്കിന് ബുക്ക് ചെയ്തോ? പ്രശ്നമില്ല" are distinguished from cancellations, preserving the tentatively held slot.

Side-Query Protection

Queries like "എന്റെ പേരായിട്ടെന്താ സേവ് ചെയ്തേക്കുന്നത്?" ("What did you save as my name?") are answered immediately without wiping the clinic appointment slot.

3. Indic Spoken DateTime Formatter (Prosody Tuning)

When TTS engines receive raw ISO strings like 2026-11-11T10:00:00+05:30, they read them digit-by-digit like a robot. Kelvi AI converts timestamps into natural colloquial phrasing before sending text to Timbre:

# Raw timestamp "2026-11-11T10:00:00" # Formatted Indic Spoken Text (Malayalam) "നാളെ (നവംബർ 11) രാവിലെ 10:00-ന്" # Formatted Indic Spoken Text (Hindi) "कल (11 नवंबर) सुबह 10:00 बजे"

4. Data Sovereignty & Telephony Security

100% Indian On-Premise

Speech and reasoning execute entirely on Gnani Artha infrastructure within India. No voice data or transcripts cross sovereign borders.

Zero Audio Retention

Microphone audio is validated in memory and discarded immediately after transcription. No audio recordings are saved to disk.

Automatic PII Masking

All caller telephone numbers in database records, call events, and operations dashboards are cryptographically masked (e.g. +91 ••••• •3210).
