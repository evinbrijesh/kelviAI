Introduction

Kelvi AI Developer Documentation

Kelvi AI ("Kelvi" = Hearing / Question in Dravidian languages) is an open-source, Indian-language-first framework for building reliable voice agents that take actions in the real world.

Traditional voice bots pipe raw speech to overseas LLMs, resulting in 3 to 4 second turn latencies, robotic English pronunciations of Indian numerals, and dropped calls. Kelvi AI combines fast deterministic rules (<2ms) with sovereign Indic reasoning models, telephone-grade acoustic models, and declarative Python tools.

Core Framework

Session lifecycle, conversation history, memory, tool registration, confirmation handling, and telemetry.

Indic Layer

Script detection, code-mixed language resolution, transliteration, and natural spoken datetime prosody.

Reference Apps

Working demonstrations including outpatient clinic scheduling and quick-commerce delivery support.

Quickstart

Running Kelvi AI Locally

To run the reference service and local voice demo on your development machine, clone the repository and configure your environment variables: 

# 1. Clone repository
git clone https://github.com/evinbrijesh/vaanikit.git
cd vaanikit

# 2. Create Python virtual environment (Python 3.11+)
python -m venv .venv
source .venv/bin/activate

# 3. Install dependencies in editable mode
pip install -e ".[dev]"

# 4. Configure environment
cp .env.example .env
# Add your GNAI_API_KEY_ID in .env

# 5. Start development server
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

Once running, access the local service at:

  • • Interactive Voice Demo: http://localhost:8000/demo
  • • Call Operations Dashboard: http://localhost:8000/admin/ui
  • • Technical API Reference: http://localhost:8000/api-reference

Interactive Speech Endpoints

The voice service exposes clean REST endpoints for browser audio worklets and telephony gateways:

Endpoint Method Purpose
/api/voice/session/start POST Initialize a call session and synthesize the opening regional greeting. Accepts agent_type: "clinic" | "delivery".
/api/voice/session/{call_sid}/turn POST Upload recorded microphone WAV audio. Transcribes via Prisma STT, processes state turn, and synthesizes reply audio.
/api/voice/session/{call_sid}/text-turn POST Send typed text fallback for testing without a microphone. Synthesizes full audio response.
/api/voice/session/{call_sid}/audio GET Download or stream the latest synthesized 48kHz WAV audio chunk.
/api/voice/session/{call_sid}/reset POST Reset dialogue state and release demo database locks.

For interactive parameter schema inspection and cURL testing, visit the Interactive API Reference (/api-reference).

Action Execution

The @tool Decorator & Confirmation Guardrails

Kelvi AI turns normal Python functions into voice-executable actions with automated JSON schema parameter generation and safety confirmation checks: 

from kelvi import tool

@tool(
    name="cancel_order",
    description="Cancel active customer order before dispatch",
    requires_confirmation=True,  # Safety guardrail: auto-asks confirmation in caller's dialect!
    confirmation_prompt={
        "ml-IN": "ഓർഡർ റദ്ദാക്കണമെന്ന് ഉറപ്പാണോ?",
        "hi-IN": "क्या आप आर्डर रद्द करना चाहते हैं?",
        "en-IN": "Are you sure you want to cancel your order?",
    }
)
async def cancel_order(order_id: str) -> dict:
    return {"status": "cancelled", "refund": "₹340"}

When requires_confirmation=True is specified, the runtime intercepts execution, pauses the action, and asks for confirmation in the caller's regional dialect. If the caller affirms (e.g. "അതെ", "ശരി", "हाँ"), the tool executes. If the caller cancels, the session safely preserves state.

Indic Intelligence

Indian-Language Engine

Voice agents in India must handle code-mixing (Manglish, Hinglish) and regional linguistic constructs:

1. Supported Regional Languages

Language Code TTS Voice Transliteration Target
Malayalam ml-IN Reshma Manglish (Latin)
Hindi hi-IN Nalini Hinglish (Latin)
Tamil ta-IN Asmita Tanglish (Latin)
Telugu te-IN Suhana Telugu-English
Kannada kn-IN Saanvi Kannada-English
Bengali bn-IN Kirra Benglish

2. Spoken Datetime Formatter

Raw timestamps (2026-11-12T10:00:00) produce robotic recitation on voice synthesizers. Kelvi AI formats temporal slots into natural conversational syntax before TTS:
2026-11-12 10:00 AM → "നാളെ രാവിലെ 10:00-ന്"

Safety

Telephony & Privacy Safeguards

Kelvi AI is built with healthcare and financial data protection rules in mind:

  • • Zero Audio Persistence: Raw microphone audio is held in memory during the turn and never written to permanent disk storage.
  • • Automatic PII Masking: Caller phone numbers are masked in all logs and API responses (+91 90000 ***01).
  • • Input Size Bounds: Audio payloads exceeding 10MB are rejected immediately before hitting speech models.
  • • Signature Verification: Twilio webhooks enforce cryptographic HMAC-SHA1 validation.
