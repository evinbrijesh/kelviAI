The Framework & The Reference Application

Kelvi AI decouples Indian voice orchestration, conversation state, and telephony safety from domain-specific business logic.

Core Architecture

Kelvi AI Core

A reusable, domain-agnostic runtime for building reliable voice agents across industries:

  • Conversation state: Explicit turn lifecycle, context preservation, and slot locking.
  • Memory: Strips colloquial fillers and retains context across multiple turns.
  • Tool execution: The @tool decorator with automatic schema generation and confirmation guardrails.
  • Provider adapters: Swap STT, reasoning, and TTS without touching application code.
  • Indic language handling: Script detection, code-mixing tolerance, transliteration, and spoken datetime prosody.
  • Safety and observability: Sub-second Engine X-Ray telemetry and chronological event audit trails.

Healthcare Reference Application

Appointment Assistant

A production reference application demonstrating clinic scheduling over browser audio and Twilio telephony:

  • Malayalam and Hindi interaction: Understands colloquial temporal phrasing ("നാളെ രാവിലെ 10 മണിക്ക്").
  • Availability checks: Queries calendar slots with conflict resolution.
  • Alternative-slot suggestions: Recommends nearest available opening when a slot is booked.
  • Confirmation before booking: Guardrail requires caller agreement before committing appointments.
  • PostgreSQL persistence: Partial unique index locking prevents double bookings.
Dialogue Lifecycle

See the Framework in Action

How a caller utterance travels from microphone audio to real-world database action and voice reply:

Step 01
Speak

Caller speaks naturally in Malayalam, Hindi, or code-mixed speech into the microphone.

Step 02
Understand

Prisma STT transcribes telephonic audio while the Indic layer identifies script and language.

Step 03
Reason

Fast deterministic rules resolve in under 2ms, with Evon v3.3 reasoning for complex back-references.

Step 04
Call a tool

The runtime executes typed Python functions with schema validation and confirmation checks.

Step 05
Persist result

Bookings, state transitions, and chronological event traces commit to PostgreSQL.

Step 06
Respond naturally

Spoken datetime prosody and Timbre TTS generate fluid, localized voice responses.

Add a tool

Your business logic stays in normal Python. Kelvi AI handles schema validation, conversation context, execution, and confirmation checks: 

from kelvi import tool

@tool(
    name="check_availability",
    description="Check whether a requested slot is available",
    requires_confirmation=False,
)
async def check_availability(date: str, time: str) -> dict:
    return await calendar.find_slot(date, time)

Indic Engine

Native parsing for 10 Indian languages with code-mixing tolerance, filler stripping, and spoken datetime prosody: 

from kelvi.indic import resolve_language, format_spoken_datetime

# 1. Resolve code-mixed requests (e.g. Hinglish or Manglish)
lang = resolve_language("Mujhe kal subah 10 baje slot chahiye", hint="hi-IN")
# Returns: "hi-IN"

# 2. Format temporal slots into natural conversational syntax before voice synthesis
spoken = format_spoken_datetime("2026-11-12", "10:00", language="ml-IN")
# Returns: "നാളെ രാവിലെ 10:00-ന്" (smooth prosody without robotic digit recitations)
