The Framework & The Reference Application

Kelvi AI decouples voice orchestration, conversational state, and telephony safety from domain business logic.

Layer 1: The Core Framework

Kelvi AI Agent Engine

An extensible runtime providing zero-latency hybrid gating, conversational memory trap prevention, spoken datetime prosody tuning, and dual-script transliteration for Indian telephony.

  • Declarative Agent Spec: Define persona, language, voices, and tools via clean YAML.
  • Dual-Engine Gating: Fast deterministic Indic rules (<2ms) with Evon v3.3 reasoning fallback.
  • Credit & Token Shield: LRU speech synthesis caching and 0-byte audio guards.
  • Telephony Security: HMAC-SHA1 webhook verification, IDOR safeguards, and 10MB bounds.
Layer 2: The Reference Application

Outpatient Clinic Assistant

A hosted scheduling assistant demonstrating stateful appointment booking, slot conflict resolution, and colloquial code-mixing (Manglish, Hinglish) over browser audio and Twilio.

  • Transactional Booking: Partial unique index locking prevents double bookings.
  • Conflict Suggestion: Recommends nearest available slot if requested hour is taken.
  • Dual-Script Transliteration: Live Latin phonetic badges for non-native listeners.
  • Audit Trail: Full chronological state transitions, latencies, and tool calls.

The Artha Sovereign Triad

End-to-end execution on sovereign Indian models with local deterministic guardrails.

Confirmations and clean dates resolve immediately through local rules using 0 LLM tokens and 0 credits.

Filler Immunity

Data Sovereignty

100% on-premise execution with automatic phone masking and zero raw audio persistence.

Declarative Agent Configuration

Create production voice agents in standard YAML without touching audio drivers or SIP gateways:

agent:
  name: "clinic-scheduler"
  language: "ml-IN"
  greeting: "നമസ്കാരം, ഞാൻ കേൾവി AI അസിസ്റ്റന്റ് ആണ്. എങ്ങനെ സഹായിക്കാം?"
  persona: "Helpful medical appointment assistant"

model:
  provider: "gnani"
  stt: { model: "prisma-v3.0", language: "indic-auto" }
  tts: { model: "timbre-v2.5", voice: "Reshma" }
  date_time_resolver: "evon"

tools:
  - name: "check_availability"
  - name: "book_slot"
  - name: "cancel_booking"
  - name: "reschedule_booking"
